# README media

[← Project overview](../../README.md)

| File | Content and source |
| :--- | :--- |
| `intent-handover.gif` / `.mp4` | Full Strategy screwdriver replay with a fixed right receiver, shown simultaneously from workspace and grasp-detail cameras. Rendered in the companion's laboratory scene using the same saved trajectory. |
| `receiver-gallery.gif` / `.mp4` | Four A2 replays: can and screwdriver, each with a left and right receiver in the outward sampling region. Full-arm views show posture-reviewed examples from the seeded receiver bank. |
| `paper-method.png` | Fig. 2 extracted from the supplied Intent-Handover manuscript, also available on the [project website](https://robot-future.github.io/intent-handover/). |

The animations are compact looping previews; the adjacent MP4 files provide
standard video playback. Video editing changes presentation, camera arrangement
and labels. Trial IDs, source checksums and presentation settings are recorded
in [sources.json](sources.json).

For simulation media, follow the companion's [rendering guide](https://github.com/Hanxin-Zhang/r2handoversim/blob/main/docs/rendering.md)
and the [calibrated method workflow](../workflows.md#original-candidates-real-asset-pads-and-fixed-receivers).
Rendered media is stored here; robot, object and MANO model files are configured
locally through those workflows.
